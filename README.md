# Odin Recipes

A simple, clean recipe website built from scratch with only HTML as part of The Odin Project Foundations course.

**Live Demo:** https://kaburungo.github.io/odin-recipes/

### Features
- Home page with list of recipes
- 3 recipe pages: Lasagna, Kenyan Pilau, Soft Chapati
- Each recipe has Description, Ingredients (ul), Steps (ol), and Image
- Navigation links between Home and recipes (relative paths)

### Built With
- HTML5 boilerplate
- Git & GitHub for version control

### What I Learned
- How to structure HTML files with h1, h2, p, ul, ol, a, img tags
- How to use relative links: `recipes/lasagna.html` and `../index.html`
- How to organize project folders and use git add / commit / push
- How to deploy a site with GitHub Pages
